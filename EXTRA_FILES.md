# Large files outside the git tree

The files below are too large for the git tree. They are meant to be uploaded as release assets or to the Zenodo record of this repository. Sizes and SHA-256 hashes are listed in `extra/MANIFEST_SHA256.csv`, which is generated next to the files.

| File | Content |
|---|---|
| `ycbv_external/external_bop_labels.csv` | BOP errors and recall labels of every YCB-V candidate |
| `ycbv_external/observable_candidate_features.csv` | 191 observable features of every YCB-V candidate |
| `ycbv_external/scores.csv` | Registration scores of every YCB-V candidate |
| `tless_development/observable_candidate_features.csv` | Features of the 22-object development bank |
| `tless_unseen/unseen5/observable_candidate_features.csv`, `tless_unseen/unseen3/observable_candidate_features.csv` | Features of the unseen T-LESS banks |
